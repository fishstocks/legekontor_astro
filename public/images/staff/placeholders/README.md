# Eksempelportretter

Disse seks portrettene er genererte eksempelbilder for design og testing.
De viser ikke ansatte ved Vågsbygd legesenter og skal erstattes med godkjente
bilder før publisering.

Generert med OpenAI sitt innebygde bildeverktøy 27. juli 2026. Felles
bildespesifikasjon: fiktive fastleger, lyst skandinavisk klinikkmiljø, mykt
nordisk dagslys, nøytrale klær, ingen logoer, navneskilt eller lesbar tekst.
